# LAB2 Runtime Instructions

## Prerequisites

- GNU Radio Companion (GRC) 3.10+ installed on your desktop or on the Raspberry Pi.
- Python 3 runtime with GNU Radio libraries if you intend to execute generated flowgraphs locally.

## Using the GRC projects

1. Launch GNU Radio Companion.
2. Open the desired `.grc` flowgraph from the `GRC` directory via **File → Open**.
3. Review the block parameters, especially hardware source/sink blocks, and adjust device names to match your SDR (e.g., RTL-SDR, USRP).
4. Click **Generate** to export the Python script, then **Run** to execute the flowgraph.
5. Capture logs and screenshots for lab reports and save them alongside the flowgraph files.

## Notes

- Place any support recordings, IQ captures, or auxiliary scripts inside the `GRC` folder so the project stays self-contained.
- The autogenerated temporary files (for example `~WRL0216.tmp`) can be ignored; they are covered by the repository `.gitignore` rules.
